# Copilot Instructions for Tikkun Korim Project

## CRITICAL FORMATTING PROTECTION RULES

### 🚫 NEVER MODIFY THESE CSS CLASSES AND THEIR FORMATTING:

#### `.amud-content` - Core Content Container
- **NEVER** change padding, margins, border, background, or any layout properties
- **NEVER** modify responsive breakpoints or media query adjustments
- **NEVER** alter the structure or positioning of this container

#### `.text-line` - Hebrew Text Line Formatting
- **NEVER** change font-family, font-size, direction, or text alignment
- **NEVER** modify margin, padding, or spacing properties
- **NEVER** alter unicode-bidi, word-wrap, overflow-wrap, or hyphens settings
- **NEVER** change box-sizing or width properties
- This class is critical for proper Hebrew text rendering and Torah layout

#### Text Line Layout Types - **ABSOLUTELY PROTECTED**:
- `.text-line.satum` and `.text-line[class*="satum"]`
- `.text-line.patuch`
- **NEVER** modify justify-content, text-align, or display properties
- **NEVER** change the flex layout behavior for satum lines

#### `.text-fragment` and `.text-fragment.word`
- **NEVER** modify display properties or text flow behavior
- These control proper Hebrew word rendering and text layout

#### Aliyah and Verse Markers - **COMPLETELY OFF-LIMITS**:
- `.aliyah-markers`, `.aliyah-marker`
- `.verse-index`
- `.labelright`, `.labelright .pasuk`
- `.labelleft`, `.labelleft .aliya`
- **NEVER** change positioning, colors, sizes, or layout of these elements
- These provide critical Torah reading navigation markers

#### Responsive Breakpoints - **STRICTLY PROTECTED**:
- All `@media` queries for `.amud-content` and `.text-line`
- **NEVER** modify mobile/tablet font sizes or spacing adjustments
- These are carefully calibrated for readability across devices

## What You CAN Modify:
- Header and Footer components (but not their interaction with amud-content)
- Loading and error states (outside of amud-content)
- Navigation functionality
- Data loading and processing logic
- TypeScript types and interfaces
- Utility functions

## Why These Rules Exist:
The `.amud-content` and its internal formatting represent the core Torah text layout that must maintain:
1. **Religious accuracy** - Proper Hebrew text flow and Torah column layout
2. **Readability** - Carefully tuned typography for Hebrew reading
3. **Traditional formatting** - Satum/Patuch line types follow centuries-old traditions
4. **Accessibility** - Font sizes and spacing optimized for various devices

## When in Doubt:
If you're unsure whether a change affects protected formatting, **DON'T MAKE THE CHANGE**. Ask the user for explicit permission before modifying any CSS related to text rendering, layout, or positioning within the amud-content area.
